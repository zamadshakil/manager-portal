## 2. System Summary

The **Hierarchia Manager Portal** is a completed web-based enterprise workflow platform built to help organizations manage teams, assign work, receive document submissions, validate those submissions using AI, collaborate internally, and monitor performance through dashboards and reports.

### Core business outcomes supported by the system

- Replace manual document review with AI-assisted evaluation
- Centralize task assignment and submission tracking
- Provide controlled access for admins, managers, and members
- Enable real-time communication inside the platform
- Improve operational visibility through analytics and audit logs
- Support secure storage, validation, and retrieval of organizational documents

## 6. Commercial Notes

This final quotation is prepared on the following commercial basis:

- The quotation covers the **complete portal scope** listed in this document as completed.
- The total commercial value is fixed at **PKR 1,100,000**.
- Approximately **53% of the quotation value (PKR 580,000)** is intentionally weighted toward the platform's **self-hosted real-time messaging system and user access control/RBAC layers**, reflecting the highest-complexity and highest-value implementation effort.
- The quotation reflects completed software design, development, integration, testing, deployment, and handover support.
- Post-delivery revisions and ongoing maintenance are evaluated separately based on scope and complexity.
- Third-party recurring charges are **not included** unless separately agreed.

Examples of third-party or recurring items that are typically billed separately:

- Cloud hosting / server charges
- Domain and SSL costs
- Cloud storage costs
- AI API usage charges
- Email/SMS gateway charges
- Ongoing maintenance after warranty/support period
